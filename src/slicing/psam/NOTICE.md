# PS AM Print source provenance

`zip-inspection.js` extracts bounded ZIP inspection/read helpers, slice metadata
parsing, and printer-model normalization from
`slicer-output-validator.js` in `3dprintingworldinc-lang/psam-server-transition`,
commit `74941370890ce3fe26ed43deb475b221b4a387d3`, under
`source-snapshot/portal-source/`. The helper bodies are preserved; default size
limits are reduced for desktop intake. Unrelated PS AM material, bed, nozzle,
and manufacturing policy code is not included. Copyright and upstream rights
remain with their owners. This local build does not publish private source.
